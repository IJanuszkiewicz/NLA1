Make sure to run these commands before compiling:
```bash
apptainer shell /path/to/amsc_mk_2025.sif
source /u/sw/etc/bash.bashrc
module load gcc-glibc
module load lis
```

To compile 
```bash
make
```

To run
```bash
make run
```

To clean
```bash
make clean
```


## Project structure

```
.
├── src/
│   ├── main.cpp
│   ├── functions_IO.cpp    # input/output helpers
│   ├── functions_IO.hpp
│   ├── tests.cpp           # scratch code, not compiled
│   └── deer.jpg            # input image
├── libs/                   # stb single-header libraries
├── outputs/                # created at runtime
├── Makefile
└── README.md
```

- `src/main.cpp`: runs the tasks one after the other and prints the results.
- `src/functions_IO.cpp` / `.hpp`: reading and writing images (png), Matrix
  Market files (mtx) and LIS matrices/vectors.
- `src/tests.cpp`: tests, demos and code from the labs, kept only as a
  reference for the libraries. It is not part of the build.
- `libs/`: `stb_image.h` (image loading) and `stb_image_write.h` (png saving).
- `outputs/`: one folder per task. It is generated by `make run` and deleted by `make clean`.
